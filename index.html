1. Payoff table

Enter the payoff for each alternative in every state of nature. Higher values are assumed to be better (profits, benefits or returns).

State probabilities must total 1 (100%).

2. Summary

Statistics are calculated from the complete original set of alternatives.

Alternative statistics

EMV = weighted expected payoff · Regret = best payoff in a state minus the alternative's payoff.

3. Criterion decisions

Each criterion independently evaluates every original alternative. All ties are reported.

How to interpret: Maximax chooses the highest possible payoff (optimistic); Maximin chooses the best worst-case payoff (cautious); Minimax Regret minimizes the largest possible regret; EMV/Bayes chooses the highest probability-weighted expected payoff.

4. Staged filtering

Create an ordered sequence of rules. Each stage only evaluates alternatives that survived the previous stage. Ties at the cutoff survive.
